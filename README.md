# 🏋️ FitTrack

A modern Flutter-based Fitness Tracker application that helps users manage workouts, monitor fitness progress, calculate BMI, and achieve daily fitness goals.

---

## 📱 Features

- 🔐 Firebase Authentication
- 👤 User Profile with Profile Picture
- 💪 Add, Edit & Delete Workouts
- 📊 Workout Summary Dashboard
- 📈 Weekly Progress Analytics
- 📉 Workout Chart
- 🎯 Fitness Goals
- ⚖️ BMI Calculator
- 🔍 Workout Search
- 🔄 Pull to Refresh
- 🌙 Dark Mode Support
- 👋 Personalized Greeting
- 💬 Daily Motivation Quotes
- 📱 Responsive UI
- 🎨 Modern Material Design

---

## 🛠 Tech Stack

- Flutter
- Dart
- Firebase Authentication
- SQLite
- Shared Preferences
- Material Design

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/harshitZ1/FitTrack.git
```

### Install Dependencies

```bash
flutter pub get
```

### Run App

```bash
flutter run
```
